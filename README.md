# TEAM COLORS — VS Code用プロジェクト

## 開き方
1. ZIPを展開する
2. VS Codeで `team-colors-vscode` フォルダーを開く
3. `index.html` をブラウザで開く（またはVS CodeのLive Server拡張で「Open with Live Server」）

## ファイル構成
- `index.html` : 5ページの画面構成
- `css/style.css` : デザイン・スマートフォン対応
- `js/script.js` : 50問の診断、採点、8タイプ、相性チェック、回答保存

※ 診断結果や回答はブラウザのlocalStorageに保存されます。
